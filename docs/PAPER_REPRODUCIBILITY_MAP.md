# Manuscript-to-repository reproducibility map

**Article:** CISD-Net: Closed-Form Orthogonal Decomposition Eliminates Subspace Leakage in Field Plant Disease Recognition

**Author:** Saed Alqaraleh (sole author). The journal article DOI is pending.
The earlier software DOI (10.5281/zenodo.24263471) archives **v1.0.0
only**. A new version-specific DOI for the updated source will be recorded
here when that release is archived.

## Exact numerical reproduction

From the repository root, using Python 3.11:

```bash
python -m pip install -r requirements-verify.txt
python -m pip install -r requirements-analysis.txt
python scripts/verify_reproduction.py
python analysis/recompute_v3.py
python analysis/verify_reference.py
python scripts/audit_manuscript_alignment.py
```

The prediction replay validates all 99 frozen NPZ archives. The analysis
script derives numerical outputs from the immutable predictions and ledger,
without executing the image encoders or retraining a model. The comparison
script checks all entries available from those public inputs.

## Protocols and summary definitions

- P1 and P2 use the same PlantDoc cohort of 2,185 images in 24
  classes, with two distinct train/validation/calibration/test partitions.
- FP uses 1,273 FieldPlant images in five classes. Partitions are disjoint
  by **export file stem**, not by perceptual-image identity.
- Eleven configurations × three seeds (42, 108, 2026) × three protocols
  yield the 99 frozen prediction archives. Values shown with `±` in
  the manuscript use **sample standard deviation (ddof=1)**.
- Manuscript Table 2 reports the **maximum** cross-block overlap
  `||U_P^T U_B||_F` over the three seed checkpoints, whereas the
  comprehensive README summary also displays **mean** overlap.
  Manuscript Table 2 displays HSIC in units of `10^-3`; the run ledger
  stores it unscaled. The largest measured Cayley overlap across all
  36 uses of the joint frame is 2.0220069661553594e-15.
- Accuracy intervals use 20,000 paired bootstrap resamples and selected
  random-sign p-values use 20,000 assignments. AURCC and conformal-set
  size intervals use 2,000 paired bootstrap resamples.

## Limits of what the public archive establishes

**Fully reproducible from repository files:** SHA-256 checks, evaluation
metrics and conformal sets for 99 prediction archives, six LaTeX table
bodies, two data figures, and the comparisons supported by the published
prediction/ledger inputs.

**Archived reference only, pending additional pHash input:** The
perceptual-hash audit recorded 35 near-duplicate pairs, 19 across
partitions, affecting 10 FieldPlant test images. The sensitivity results
and 11 additional `FPclean` contrasts are stored in the original
`analysis/numbers_v3.json`, but independently rerunning them requires
an earlier FieldPlant manifest containing `sha256` and `phash`.
That manifest is not distributed here.

**Independent GPU model regeneration requires external resources:**
the original photographs and pretrained backbones are available from
their respective upstream providers, subject to their licenses. The
75.6 MB frozen four-view embedding cache, fitted checkpoints, and
raw photographs are not in this Git repository. The complete 99-head
GPU rerun is a distinct workflow and is not asserted to have been
independently reproduced by the CPU verification script.

**Ledger-only measurements:** HSIC, Stiefel overlap and view-gate
statistics are stored in the frozen numerical ledger. The public
prediction NPZs do not contain sufficient projected features or model
matrices to recompute those statistics from first principles.

The Cayley frame uses the Stiefel Cayley transform of Jauch, Hoff and
Dunson (2020, *Bernoulli* 26(2):1560–1586,
https://doi.org/10.3150/19-BEJ1176). The transform itself is not
claimed as a new mathematical construction.
